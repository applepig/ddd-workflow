# Skill: DDD:xwrap

## 說明
收工階段。進行最終檢查、確保文件完整、推送分支準備 PR。

## 觸發指令
`/DDD:xwrap`

## 輸入
已完成所有 milestone 的 sprint 文件包。

## 執行步驟

1. **任務完整性檢查**
   - 確認 tasks.md 中所有項目已勾選
   - 確認所有測試通過（執行完整測試套件）

2. **文件完整性檢查**
   - `spec.md`：驗收條件是否全部滿足
   - `tasks.md`：是否全部勾選完成
   - `works.md`：是否記錄了重要的技術決策與問題解決

3. **程式碼品質檢查**
   - 確認沒有遺留的 TODO / FIXME / console.log
   - 確認沒有未使用的 import 或變數
   - 確認測試覆蓋了 spec 中的驗收條件

4. **推送與報告**
   - 推送分支到遠端
   - 產出 sprint 摘要報告：
     - 完成了什麼
     - 重要的技術決策
     - 已知的限制或後續改善建議

## 產出
- 推送到遠端的 feature branch
- Sprint 摘要報告（在對話中呈現）

## 結束條件
分支推送完成，使用者可以建立 Pull Request。
